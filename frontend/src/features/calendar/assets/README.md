# Service logos

Shown on the meeting reminder's Join button (`components/service-logo.tsx`).

- `google-meet.svg`: the Google Meet glyph from [Simple Icons](https://simpleicons.org) 13.21.0 (CC0-1.0), filled in Meet green.
- `zoom.svg`, `teams.svg`: drawn for Deino in the style of each app's icon (a camera on Zoom blue; a "T" on Teams purple). Simple Icons no longer ships Microsoft logos.
