# Deino

Deino is an open-source, local-first AI meeting notepad for macOS. It records the
microphone and system audio on your Mac, transcribes locally, and turns the
transcript and your own notes into structured meeting notes. Recording,
transcription, storage and search all run on the Mac; the only data that leaves
it goes to the LLM provider and integrations you choose to connect.

## Stack

- One Tauri 2 app: the app crate in `frontend/src-tauri/`, Tauri-free crates in
  `crates/` (`deino-domain`, `deino-db`, `deino-core`), and a React 18 UI built
  with Vite, TanStack Router, TanStack Query and Tailwind v4 in `frontend/src/`.
- Typed IPC generated by tauri-specta into `frontend/src/lib/ipc/generated/`.
- SQLite through sqlx, with migrations in `crates/deino-db/migrations/`.
- Local transcription (Parakeet via ONNX Runtime, Whisper via whisper.cpp).
- Sidecars: `llama-helper` (built-in local LLM, this workspace), the `deino`
  CLI and MCP server (`crates/deino-cli`, bundled as `cli`; give Claude Code
  your meetings with [docs/setup/claude-code.md](docs/setup/claude-code.md)),
  and FFmpeg (downloaded and SHA-256 verified by the build script).

## Requirements

- macOS 14.2 or later on Apple Silicon (primary target). Windows and Linux
  must still compile.
- Rust (the version in `rust-toolchain.toml`, installed by rustup), Node.js 20+,
  pnpm 9+, Xcode Command Line Tools and CMake.

## Run in development

```bash
# 1. Build the llama-helper sidecar once and stage it where Tauri expects it
cargo build --release -p llama-helper --features metal
mkdir -p frontend/src-tauri/binaries
cp target/release/llama-helper \
   "frontend/src-tauri/binaries/llama-helper-$(rustc -vV | sed -n 's/^host: //p')"

# 2. Build the deino CLI and stage it as the `cli` sidecar
scripts/stage-cli.sh

# 3. Install UI dependencies and start the app
cd frontend
pnpm install --frozen-lockfile
pnpm run tauri:dev
```

The first Rust build downloads the pinned FFmpeg sidecar into
`frontend/src-tauri/binaries/`.
