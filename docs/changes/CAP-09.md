- Crates: add `deino-screen` (screen capture: `PHash`, `SnapshotSampler`, `decide`, `Capture`/`Capturer`, `ScreenCapture`; ScreenCaptureKit and `AVAssetWriter` through cidre; no network, no tauri).
- Pipeline: stage `screen_video` (order 15) after `finalize_audio`: gives `video.mp4` the mixed audio, stores `video_path`.
- Files: `<recordings>/<meeting>/video.mp4` (with sound after `screen_video`) and `snapshots/<ms>.png`.
- Pipeline (phase B): stage `screen_context` at **order 45**, between `vocab_fixups` (40) and `enhance_notes` (50), so the notes are written with the screen's text; §4.2's table should move it from 55 to 45 ("runs before 50" resolved by ordering, no re-run of NOT-02). Its port is `StagePorts::screen_context` (`ScreenContextReader`), built in `composition/screen.rs::context_reader`.
- LLM routes: add `vision.describe` (Fast tier; a picture goes with the prompt as `Part::Image`, which only the Anthropic adapter sends; `GatewayDescriber` refuses any other provider by checking the route's target first).
- NOT-02 material: `Material.screen` (`ScreenText`: at, OCR text, description), rendered as `[screen mm:ss] …` lines among the transcript lines; redacted like the transcript.
- `deino-screen`: `pick` (`CaptureTarget`, `Source`, `TargetChoice`, `choices`, `resolve`), `recognize_text` (Vision OCR), displays as a capture source.
